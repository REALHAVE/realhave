# RealHave(리얼해브) 실서비스 개발 킥오프 — Claude Code용

> 사용법: 이 파일과 목업 4개를 Claude Code 프로젝트 폴더에 넣고, 아래 "5. 첫 요청문"을 그대로 붙여넣어 시작하세요.

## 1. 프로젝트 개요
- **서비스**: 국내 백화점·면세점·로드샵에서 구입한 상품만 거래하는 중고명품 개인간 거래 플랫폼 (당근마켓식: 글쓰기로 등록 → 채팅으로 협의)
- **결제 기능 없음** (1단계). 회원이 늘면 2단계에서 추가
- **참고 파일 (같은 폴더에 넣을 것)**
  - `realhave-mobile-main.html` — 모바일 화면·흐름의 기준 (가장 중요)
  - `realhave-admin-full.html` — 관리자 페이지 기준
  - `realhave-handoff-spec.md` — 브랜드·기능 요구사항
  - `realhave-integration-demo.html` — 모바일↔관리자 연동 방식 참고
- 목업은 **설계도**입니다. 코드를 복사하지 말고, 화면 구조·문구·흐름·색상을 그대로 따라 새로 구현해주세요.

## 2. 기술 스택 (가장 저비용 구성)
- **프론트**: 모바일 웹앱(PWA). React 기반(Next.js 권장) + TypeScript
- **백엔드**: Supabase (인증, Postgres DB, 이미지 저장, Realtime 채팅)
- **호스팅**: Vercel 또는 Netlify
- **디자인**: 메인 `#4D1437`, 딥플럼 `#34092A`, 브라스 `#B08D57`, 크림 `#F7F2EA`. 로고 R은 Playfair Display, 나머지는 Fraunces + Noto Sans KR
- 앱스토어 앱은 이후 단계에서 검토 (지금은 웹앱 우선)

## 3. 목업에서 확정된 규칙 (반드시 반영)
**로그인 규칙**
- 상품등록·찜·채팅은 로그인해야 이용 가능. 로그아웃 상태에서 누르면 로그인 화면으로 이동
- 하단 탭: Home / Category / A-Z Designers / My page. 로그아웃 상태면 My page 옆에 "(Log in)" 표시
- 마이페이지: 로그인 전엔 로그인 유도 카드+공개 메뉴만, 로그인 후엔 프로필·통계(구매내역/판매내역/찜/채팅)·메뉴

**상품등록 항목 (순서대로)**
사진 → 제목 → 브랜드(검색 선택) → 카테고리 → 구매처 → 사이즈 → 거래방식 → 상태등급 → 색상 → 판매가격 → 자세한설명
- 구매처: 국내(H백화점·L백화점·S백화점·로드샵·면세점·국내구매), 해외(백화점·로드샵·면세점·구매)
- 사이즈: 신발·의류 카테고리일 때만 활성화. 신발 180~300(5단위), 의류 44/55/66/77/90/95/100/103/105/110/115/그외
- 거래방식: 직거래/일반택배/반값택배 (**복수선택**)
- 상태등급: NEW/A+/A/B+/B/C
- 색상: 12색 (**복수선택**), 상세화면에 "(등록상품과다를수있음)" 고정 문구

**상품상세 화면 상태 분기**
- 일반: 사진 위 ♡, 하단 "♡ 찜 / 메시지"
- 판매내역에서 진입한 본인 상품: 찜 관련 아이콘 숨김
- 거래완료 상품: 하단에 "거래완료" 라벨만 표시

**판매/구매 흐름**
- 판매내역: 판매중/거래완료 탭, 카드별 조회수, "끌어올리기"
- ⋮ 메뉴 — 판매중: 거래완료로 변경 / 게시글 수정 / 삭제 · 거래완료: 재등록 / 삭제
- "거래완료로 변경" → **구매자 선택**(최근 채팅 상대 중 선택) → 거래완료 처리
- 탈퇴: 판매중 상품이 있으면 먼저 삭제하도록 안내 → 없으면 "대화내용·거래내용 모두 삭제" 경고 후 예/아니요

**관리자**
- 정품인증 심사(승인/반려), 카테고리·브랜드 추가/수정/삭제, 회원 자격중지/자격허용/삭제

## 4. 개발 원칙
1. **한 번에 한 단계씩** 진행하고, 단계가 끝날 때마다 "확인 방법"을 한국어로 설명해주세요. (저는 비개발자입니다)
2. 비밀키는 반드시 `.env`로 관리하고 코드에 직접 넣지 마세요.
3. Supabase는 **모든 테이블에 RLS(행 단위 보안)** 를 적용해주세요.
4. 개인정보는 최소한만 수집하세요.
5. 모르거나 정해지지 않은 건 추측하지 말고 먼저 질문해주세요.
6. 정품인증 AI는 1단계에서 **관리자 수동 심사**로 구현하고, 자동 분석은 나중에 붙일 수 있게 구조만 열어두세요.

```

모바일 웹앱(Next.js + Supabase)으로 먼저 만들려고 해.

1단계로 코드는 아직 짜지 말고 아래만 해줘.

3) 프로젝트 폴더 구조와 개발 순서를 단계별로 제안해줘
4) 내가 직접 해야 하는 계정 준비 목록을 알려줘 (Supabase, Vercel, GitHub 등)

내가 확인하면 그다음 단계로 넘어가자.
```

## 6. 개발 단계 로드맵
