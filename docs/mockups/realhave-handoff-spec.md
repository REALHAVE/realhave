# RealHave (리얼해브) 앱 기획/디자인 인수인계 문서

## 1. 브랜드 개요

- **브랜드명**: 리얼해브 (RealHave)
- **의미**: 정품 상품만 취급하며, 정품 상품만 구입하라는 뜻
- **한줄소개**: 국내 백화점, 국내 면세점, 국내 로드샵에서만 구입한 상품만 판매하는 중고명품 플랫폼
- **벤치마킹**: '필웨이'(중고명품 사이트) + '당근'(편리한 개인간 거래 플랫폼) 형태
- **서비스 구조**: 구매자 ↔ 플랫폼 ↔ 개인 판매자

## 2. 핵심 차별점 (개발 시 반드시 반영)

1. **판매 등록 제한**: 국내 백화점/면세점/로드샵에서 구입한 상품만 등록 가능
   - 증명 방법: 제품 내부 한글표기 택, 또는 한글표기 정품 인보이스/구매영수증 사진 필수 첨부
2. **AI 자동 검증**: 사진 촬영 → AI가 한글표기 택을 분석 → 검증된 상품만 이후 등록 절차 진행 가능
   - 개발 시 참고: OCR(문자인식) + 이미지 대조 기술 필요. 자체 모델 개발이 어려우면 외부 OCR API 검토 필요

## 3. 디자인 시스템

- **메인 컬러**: `#4D1437` (RGB 77, 20, 55) — 와인 퍼플
- **보조 컬러**: 딥 플럼 `#34092A`, 브라스 골드 `#B08D57` (인증/포인트 컬러)
- **배경**: 크림 `#F7F2EA`, 페이퍼 화이트 `#FFFDF9`
- **폰트**: 디스플레이 - Fraunces(슬랩세리프, 로고 톤과 통일), 본문 - Noto Sans KR
- **톤앤매너**: "정품 인증서/스탬프" 컨셉 — 인증 배지, 실링(seal) 모티프 활용

## 5. 상품 노출 로직 (기획 요구사항)

- 메인화면 상품은 수시로 업데이트되어 노출됨
- 노출 순위는 **판매자 결제(광고비 등) 상태**에 따라 결정됨 — 구체적인 과금/순위 로직은 추가 논의 필요

## 6. 개발 방식

- **네이티브 앱** (iOS / Android)로 개발 예정
- 백엔드/DB, AI 인증 기능, 결제 연동은 **아직 미개발 상태** — 본 문서와 첨부 목업을 기반으로 신규 개발 필요

## 7. 첨부 파일

- `realhave-mobile-main.html` — 클릭 가능한 인터랙티브 화면 목업 (전체 9개 화면 흐름이 연결되어 있음). 브라우저로 열어서 실제 탭/버튼을 눌러보며 화면 전환 흐름을 확인할 수 있음. 실제 코드베이스로 그대로 쓰는 용도가 아니라 **화면 구조와 흐름을 전달하기 위한 참고 자료**임.

## 8. 미결정/추가 논의 필요 사항

- **[개발 코멘트] 거래방식 다중선택**: 상품등록 화면의 '거래방식'(직거래/일반택배/반값택배)은 단일선택이 아니라 **복수선택이 가능하도록 구현 필요**
- **[개발 코멘트] 사이즈 필드 활성화 조건**: 상품등록 화면의 '사이즈' 필드는 **카테고리가 신발·의류일 때만 클릭 가능하도록 활성화** 필요 (그 외 카테고리에서는 비활성화)
- **[개발 코멘트] 사이즈 옵션 자동전환**: 카테고리가 **신발**이면 사이즈 옵션이 **180~300(5단위)**으로, **의류**면 44/55/66/77/90/95/100/103/105/110/115/그외로 **자동 전환**되도록 구현 필요
- **[개발 코멘트] 색상 다중선택**: 상품등록 화면의 '색상'은 단일선택이 아니라 **복수선택이 가능하도록 구현 필요** (예: 네이비 + 핑크 동시 선택)

- AI 정품 인증 기능의 구체적 구현 방식 (자체 개발 vs 외부 API)
- 판매자 노출 순위 결제 로직 상세
- 통신판매업 신고, 전자상거래법 준수, 에스크로 시스템 등 법적 요건
- 결제대행사(PG) 선정
