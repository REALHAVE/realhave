## 결정 변경 (2026-11-18)
- PASS 본인인증은 하지 않습니다. 대신 **이메일 6자리 코드 인증**을 합니다.
- 휴대폰번호는 **필수 입력**이지만, 진짜 번호인지는 확인하지 않습니다.
- CI(중복가입 방지값)는 저장하지 않습니다. → DB 수정 파일: `supabase/migrations/20261118000009_email_auth.sql` (Supabase에 실행 완료)

## 추가 결정·규칙 (2026-11-25~26)
- 결정 15: 처리 중(미처리) 신고와 관련된 대화는 회원삭제 시 신고 기록에 증거 사본으로 보관
- 회원탈퇴 조건: 판매중 상품 0개(심사대기·반려 포함) + 나와 관련된 미처리 신고 0건(내가 한/나에 대한/내 대화에 대한 신고). 거래완료 상품은 막지 않음(탈퇴 시 함께 삭제)
- 탈퇴 경고: 신고 처리 중이면 신고 안내만, 신고 없고 판매중 상품만 있으면 상품 삭제 안내만
- 신고 처리 중인 상품은 판매자가 삭제 불가(DB 트리거) + 판매내역에서 경고. 관리자 처리완료·기각 후 삭제 가능
- 신고자는 자기 신고의 상태·사유·결과 안내만 볼 수 있음(관리자 메모·증거는 열 단위로 차단)
- 관리자 회원삭제는 신고 여부와 상관없이 가능(증거 보관)
- 결정 16: 신고 처리 중 상품은 삭제·수정 모두 불가
- 결정 17: 탈퇴 시 거래완료 상품도 삭제, 전자상거래법 제6조 기간만큼 관리자 전용 보관함에 사본 보관 → **13단계 개인정보처리방침에 반드시 명시**, 관리자는 매월 "보존기간 지난 기록 파기"

## 해결 기록 (2026-11-22)
- Vercel 환경변수: 팀 공유변수가 아니라 **프로젝트 Settings → Environment Variables**에 넣어야 합니다. Value 칸에는 `=` 뒤의 값만 넣습니다.
- 점검 주소: https://realhave.vercel.app/api/health (두 항목이 "ok"이면 정상. 키 값은 보여주지 않음)
